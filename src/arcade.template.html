A Queda das Chaves

As chaves despencam na masmorra. Você decide o caminho de cada uma.

  • ← → (ou A D, ou os botões): em cada sala, mande a chave para a esquerda se for menor ou para a direita se for maior, antes que o anel se apague.
  • A partir da onda 3 a árvore vira AVL. Quando ela tremer, aperte duas setas: a 1ª é o lado que pesa, a 2ª é o lado do filho onde a chave entrou. ←← LL · ←→ LR · →→ RR · →← RL.
  • Travou? H ou o botão Dica: a 1ª camada mostra o que olhar, a 2ª mostra o raciocínio. Cada camada custa pontos e dá mais tempo.
  • Acertos seguidos multiplicam os pontos. Cada erro custa uma vida. Uma onda sem erros devolve uma vida.
